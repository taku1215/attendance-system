# 個人事業主の手引き(Androidアプリ)

初めて個人事業主になる人向けの手引きアプリです。開業手続き・税金・確定申告などの基礎知識をオフラインで読めて、開業準備の進み具合をチェックリストで管理できます。

## 機能

画面下部のタブで「ガイド」「ツール」「チェック」「用語集」を切り替えます。

### ガイド
- 7つのカテゴリで基礎知識を解説
  1. 開業の手続き(開業届・青色申告承認申請書・屋号)
  2. 税金の基礎知識(所得税・住民税・個人事業税・消費税)
  3. 確定申告のキホン(青色/白色の違い、スケジュール)
  4. 帳簿づけと経費(家事按分・減価償却・書類の保存)
  5. 保険・年金と将来への備え(国保・国民年金・小規模企業共済・iDeCo)
  6. インボイス制度(登録の判断ポイント・2割特例・簡易課税)
  7. 請求書と源泉徴収(請求書の書き方・フリーランス保護新法)
- トップに**確定申告(3/15)までのカウントダウン**を表示

### 便利ツール
- **計算機** — 消費税(10%/8%、税込↔税抜)と源泉徴収(10.21%/20.42%)の手取りを即計算
- **税金シミュレーター** — 売上・経費・控除から所得税・住民税・個人事業税・実効税率・手取りを試算
- **かんたん帳簿** — 収入/支出を記録。月別・合計サマリーを表示し、**CSVで書き出して共有**(会計ソフト取込用)
- **請求書メモ** — 自分の情報を保存し、請求金額の計算+請求書テキストを生成してクリップボードにコピー
- **経費になる?FAQ** — 迷いやすい支出14件を ○(可)/△(按分)/×(不可) で判定、検索対応
- **節税チェッカー** — 9つの節税策のうち使えていないものを見える化(チェック状態は端末に保存)
- **年間スケジュール** — 1年間の手続き・納税カレンダー(今月を強調表示)

### チェック / 用語集
- **開業チェックリスト** — 開業前・開業時・開業後の14項目。チェック状態は端末に保存され、進捗バーで確認できる
- **用語集** — 22の専門用語を読み仮名つきで解説。キーワード検索対応

## 技術スタック

- Kotlin 2.0 / Jetpack Compose(Material 3)
- Navigation Compose(ボトムナビゲーション + 記事/ツール詳細画面)
- SharedPreferences + org.json(チェックリスト・帳簿・節税・請求書情報の永続化)
- FileProvider(帳簿CSVの共有)
- minSdk 26(Android 8.0)/ targetSdk 35

## ビルド方法

Android Studio でこのディレクトリ(`sole-proprietor-guide/`)を開くか、Android SDK がある環境で:

```bash
./gradlew assembleDebug
# APK: app/build/outputs/apk/debug/app-debug.apk
```

## 免責事項

本アプリの内容は一般的な情報の提供を目的としたものであり、税務・法務のアドバイスではありません。制度は改正されることがあるため、最新情報は国税庁サイト・税務署・税理士等にご確認ください。
