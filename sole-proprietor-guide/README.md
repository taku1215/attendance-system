# 個人事業主の手引き(Androidアプリ)

初めて個人事業主になる人向けの手引きアプリです。開業手続き・税金・確定申告などの基礎知識をオフラインで読めて、開業準備の進み具合をチェックリストで管理できます。

## 機能

- **ガイド** — 7つのカテゴリで基礎知識を解説
  1. 開業の手続き(開業届・青色申告承認申請書・屋号)
  2. 税金の基礎知識(所得税・住民税・個人事業税・消費税)
  3. 確定申告のキホン(青色/白色の違い、スケジュール)
  4. 帳簿づけと経費(家事按分・減価償却・書類の保存)
  5. 保険・年金と将来への備え(国保・国民年金・小規模企業共済・iDeCo)
  6. インボイス制度(登録の判断ポイント・2割特例・簡易課税)
  7. 請求書と源泉徴収(請求書の書き方・フリーランス保護新法)
- **開業チェックリスト** — 開業前・開業時・開業後の14項目。チェック状態は端末に保存され、進捗バーで確認できる
- **用語集** — 22の専門用語を読み仮名つきで解説。キーワード検索対応

## 技術スタック

- Kotlin 2.0 / Jetpack Compose(Material 3)
- Navigation Compose(ボトムナビゲーション + 記事詳細画面)
- SharedPreferences(チェックリストの永続化)
- minSdk 26(Android 8.0)/ targetSdk 35

## ビルド方法

Android Studio でこのディレクトリ(`sole-proprietor-guide/`)を開くか、Android SDK がある環境で:

```bash
./gradlew assembleDebug
# APK: app/build/outputs/apk/debug/app-debug.apk
```
